# Product — v1 showcase

North star: the smallest complete loop that proves adaptive combat recommendations, typing execution, magical consequence, and an observant bard. Cut breadth before identity.

---

## What it is

A **pass-the-keyboard toy** in one desktop browser tab. Session length 60–120 seconds. Not an account, RPG, or live-model demo (`§3.3`, `§24`).

| Audience | Job | Must be true |
|---|---|---|
| Judge | See the distinctive relationship in ~90s | Authored first cast, authored rerank, authored goose, one sentence of agent leverage |
| Stranger | Sit, type, fail entertainingly, hand off | Phrase obvious in ~5s, no mouse, no tutorial (`AC-ID-001`) |
| Next player in the same chair | Same loop, played cleaner | Instant restart; bard memory resets with the run |

Retention is **another run in the same tab**: restart, “one more typo,” visible rotation, keyboard handoff. Not DAU.

---

## Presentable bar (Milestone A — identity floor)

A person who has not read the spec:

1. Sees a threat and a large phrase with no menu.
2. Types without clicking (`AC-TYPE-001`).
3. Completes the phrase and sees a cast hit (`AC-ID-003`).
4. Sees a wrong letter without color-only feedback.
5. Backspaces and continues.
6. After a cast, a **different** phrase appears because something is unavailable (`AC-COMBAT-002`) — Outcome 2+.
7. One authored misfire is visibly not a clean cast (`AC-ID-004`) — Outcome 2+ goose; Outcome 1 may fizzle.
8. A bard line (text is enough) reacts to **that** event (`AC-ID-005`).
9. The run ends (win, lose, or Outcome 1 single-cast AFTERMATH).
10. One key starts a new run; focus is already there (`AC-ID-006`).

If A is true, you can present. B is rehearsal reliability. C is juice.

### Milestone B — demo cannot miss (`§26.5`)

From a clean tab, network optional:

- Encounter 1 always offers `ignis ventus` and can be cast (`AC-DEMO-001`).
- Used spell unavailable; next rec is `glacies fractura` / `BEST VS. ARMOR`.
- `ignis ventis` + Enter always yields the goose (`AC-DEMO-002`).
- Goose bard line is guaranteed and subtitled (`AC-DEMO-003`).
- No live model (`AC-DEMO-005`).
- Audio fail does not stop combat (`AC-BARD-007`).
- Restart from a fresh session (`AC-DEMO-004`).
- Agent line in one sentence (`AC-DEMO-006`).

### Milestone C — only after A+B

Handoff with no explanation. Bundled clips if present. R3F well **off** still passes A+B (`?flat=1` when the canvas exists).

## Demo script (`§26.2`, concrete)

Operator stays quiet. First keypress may unlock audio.

1. Cold tab. Lectern + well. Phrase `ignis ventus` already huge. Bard: opening line once.
2. Type it. Auto-cast. Ember wisp reacts. Reason was `BEST VS. FLESH`.
3. Point at the spent seal / new phrase `glacies fractura` + `BEST VS. ARMOR`.
4. Type `ignis ventis`, Enter. Goose. Bard: “You requested wind. The universe heard goose.”
5. If stable, hand the keyboard. Restart is `R` or `Enter` on AFTERMATH.

**Pitch (`§26.1`):** the grimoire picks; the hands perform; a typo becomes canon; the bard files it.

**Agent sentence (`§26.3`):** the agent defined and validated a small coherent book, recommendation metadata, and event-aware bard lines; the shipped game runs without the model online.

**Memorable line (`§26.4`):** “Type what the grimoire recommends. Or misspell it and discover what the universe thought you meant.”

## Success watches (rehearsal, not analytics)

Comprehension ≤5s. Goose 10/10 on the authored path. Mute play still readable. Restart without a click. Judge can repeat the identity sentence.

Kill criteria: stranger cannot find the phrase; goose is luck; restart needs a mouse; loaders are the first wait. Fix those before adding content.
